# Tríada de la información (CIA)

Proyecto React de una sola página con formato de infografía para explicar, en lenguaje simple, los tres pilares de la seguridad de la información:

- Confidencialidad
- Integridad
- Disponibilidad

Incluye una sección interactiva con barras dinámicas para mostrar el equilibrio entre los tres pilares: al subir uno, los otros se ajustan automáticamente para representar los compromisos reales en seguridad.

## Ejecutar en local

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```
